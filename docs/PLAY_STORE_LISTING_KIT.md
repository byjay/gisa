## 4. ASO(스토어 최적화) 전략

**핵심 키워드** (검색량 순): 전기기사, 전기기사 기출, 소방설비기사, 전기공사기사, CBT, 전기기사 필기, 기출문제
- 제목·짧은설명·전체설명 첫 문단에 키워드 자연 배치 ✅ (위 문구 반영됨)
- 경쟁 앱과 차별점 전면 배치: **AI 튜터 5종 캐릭터** + **왕초보 로드맵** (경쟁 10개 앱 중 유일)

**가격 전략**:
- 1단계(출시~3개월): 완전 무료 → 리뷰·설치수 확보
- 2단계: 프리미엄(광고 제거 + AI 무제한) ₩9,900 단건 or ₩3,900/월
- 근거: 경쟁 벤치마크(맞추다 ₩15,000/월, 오르조 ₩9,900/월) 대비 저가 진입

**리뷰 확보**:
- 합격 예측 80% 도달·시험 D-1 등 긍정 순간에 응원하기 카드 노출 (설정에 구현됨)
- 목표: 첫 달 리뷰 30개, 평점 4.5+

## 5. 출시 절차 요약

1. Play Console 개발자 계정 ($25)
2. `flutter build appbundle --release` → AAB 업로드
3. 스토어 등록정보(위 1번 복사) + 그래픽 자산 업로드
4. 데이터 안전 설문(위 3번 가이드) + 콘텐츠 등급 설문
5. 내부 테스트 → 비공개 테스트(12명·14일, 신규 계정 필수) → 프로덕션
6. 출시 후: 리뷰 답변 24h 내, 월 1회 콘텐츠 업데이트
