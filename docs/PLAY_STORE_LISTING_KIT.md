# 기사클럽 Google Play 등록정보 킷 — 검증 대기 초안

- 기준일: 2026-10-28
- 상태: 복사·등록 금지. 운영 로그인, 사용자별 데이터 보호, 데이터 권리, 개인정보/Data Safety, AdMob, Play Billing, 실기기 QA가 미완료다.
- 기존 문서의 AI 튜터, 합격 예측, 3,700+ 문제, 오프라인, 무가입, 개인정보 미수집 주장은 현재 코드/운영 근거가 확인되지 않아 삭제했다.
- 무료 일일 이용 + 선택형 보상 광고로 추가 이용 + 유료 광고 제거는 목표 모델이며 현재 앱에는 구현되지 않았다. 실제 구현·검증 전 스토어 문구로 약속하지 않는다.

## 스토어 문구 초안

### 앱 이름 (30자 이하)

기사클럽 - 자격증 CBT 학습

17자.

### 짧은 설명 (80자 이하)

자격증별 문제를 풀고 해설을 확인한 뒤, 오답과 이론을 다시 복습해요.

39자.

### 전체 설명 (4,000자 이하, 릴리스 APK 재검수 후 사용)

기사클럽은 국가기술자격 시험을 준비할 때 문제 풀이와 복습을 이어갈 수 있도록 돕는 학습 앱입니다.

준비할 종목을 고르고, 과목과 회차별 문제를 풀어 보세요. 답을 확인한 뒤 해설과 관련 이론으로 돌아가고, 다시 볼 문제는 표시해 복습할 수 있습니다.

• 자격증별 종목과 과목 선택
• 과목·회차별 문제 풀이
• 문제 해설과 이론 확인
• 북마크와 오답 중심 복습
• CBT 형식의 모의 풀이
• 학습 목표와 세션 진행 확인

시험 데이터 제공 범위와 최신성은 종목별로 다를 수 있습니다. 앱에서 실제 제공하는 종목과 과목을 확인하고 이용해 주세요. 학습 기록의 계정 간 동기화와 일부 서버 기능은 준비 중이며, 로그인 및 지원 범위는 출시 시 안내합니다.

기사클럽은 시험 합격을 보장하지 않습니다. 공식 시험 공고와 출제 기준은 해당 자격 주관 기관의 최신 안내를 함께 확인해 주세요.

이 초안은 현재 소스에 연결된 풀이·해설·이론·북마크·오답·CBT 흐름을 담았다. 등록 직전 해당 릴리스 APK에서 각 항목과 종목별 데이터 범위를 다시 확인한다.

## 수익 모델 — 내부 목표

- 기본 무료: 매일 기본 학습량. 정확한 수량 미정.
- 선택형 보상 광고: 매회 사용자가 선택해 시청한 뒤 앱 내부의 비양도성 추가 학습량 지급.
- 유료 상태: 기사클럽의 모든 광고 제거. 일일 학습 한도까지 무제한으로 바뀌는지는 미정.
- 가격·보상량·상한·해지/환불 문구는 결정 전. AdMob/Play Billing/서버 구매 검증은 미구현.
- 이 내용은 내부 기획이며 출시용 전체 설명에 넣지 않는다. 산식과 경쟁 모델은 [MARKETING_REVENUE_PLAN_1M.md](MARKETING_REVENUE_PLAN_1M.md).

## 이전 문서의 재사용 금지

- “AI 튜터 5종”, “왕초보 6단계”, “실시간 합격예측”, “과락 경보”, “실기 완벽 지원”, “3,700+문제”, “무가입/오프라인/개인정보 미수집”.
- “유일/최저가”, 경쟁 앱 가격을 앱스토어 확정가처럼 인용, 실제 성과인 것처럼 보이는 리뷰/평점 목표.
- 이전의 ₩9,900 단건/₩3,900 월간 가격. 현재 승인이나 수요 검증이 없다.
- “Data Safety: 데이터 수집 없음”. 광고/로그인/서버 SDK를 반영한 실제 동작 확인 후 답한다.
- 계정별 테스트 인원/기간을 고정 요건으로 복사하지 않는다. Play Console 현재 요건을 확인한다.

## 출시 전 체크

- [ ] 제목 30자, 짧은 설명 80자, 전체 설명 4,000자 제한 확인.
- [ ] 릴리스 APK에서 소개 기능과 종목별 데이터 재생.
- [ ] 로그인/계정 삭제/데이터 삭제와 사용자별 저장 구획.
- [ ] 광고 동의·개인정보 안내·테스트 광고·정책 확인.
- [ ] 유료 상태에서 모든 광고 노출 0건.
- [ ] Play 구매/복원/갱신/취소/환불/만료와 서버 entitlement.
- [ ] Data Safety·개인정보처리방침·약관과 SDK 동작 일치.
- [ ] 문제/해설 출처·이미지·폰트·라이브러리 권리 및 오류 신고 경로.
- [ ] 실기기 접근성, 작은 화면, 네트워크/API 오류 확인.
