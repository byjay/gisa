## 1. 시장 개요 (한국 자격증 학습 앱)

전기·소방 등 국가기술자격 학습 앱 시장은 **"기출문제 무료 제공"이 사실상 표준**입니다.
아래 3개 주요 경쟁자가 시장을 나눠 갖고 있습니다.

| 경쟁자 | 형태 | 수익모델 | 강점 | 약점 |
|---|---|---|---|---|
| **전자문제집 CBT (comcbt)** | 웹+앱, 커뮤니티 | **완전 무료**(구독 없음), 배너광고 | 방대한 기출 DB, 압도적 인지도, 무료 | UI 구식, 개인화·해설 품질 편차, AI 없음 |
| **맞추다 (machuda)** | 웹+앱(멀티플랫폼) | **프리미엄 = 전문가 해설 무제한**(유료) | 깔끔한 UI, 멀티디바이스, 맞춤 CBT | 해설 유료 장벽, AI 튜터 없음 |
| **전구앱 (zzinapp)** | 종목별 개별 앱 | 광고+일부 유료 | KEC 최신 반영, 종목 특화 | 종목마다 앱 분리, 통합 학습 불가 |

### 시장의 빈 구멍 (우리의 기회)
1. **AI 개인 튜터가 있는 앱이 사실상 없다** — 경쟁자 전원 "문제+해설 제공"에 머무름.
2. **학습 지속(게이미피케이션)이 약하다** — 스트릭/XP/레벨/미션으로 이탈 방지하는 앱 부재.
3. **10개 종목 통합 + 실기/속독/오답노트까지 한 앱**은 드묾(전구앱은 종목 분리).

## 2. Gisaclub 포지셔닝

> **"기출은 기본, 합격은 AI 튜터가 만든다"** — 개인 맞춤 AI 학습 코치형 자격증 앱.

### 핵심 차별점 (경쟁자가 못 가진 것)
- 🤖 **AI 튜터**: 문제별 질의응답·개념 설명·오답 원인 분석 (Cerebras 기반, BYOK/무료)
- 🎮 **게이미피케이션**: 스트릭·XP·레벨·일일 미션·마법 방패 → 학습 지속률↑
- 📚 **10종목 통합**: 전기(기사/산업기사) + 소방 + 산업안전 + 정보처리 등
- ⚡ **속독 답외우기 / 오답노트 / 기출빈도 상세** → 시험 직전 효율 학습
- 🔔 **실시간 큐넷 시험일정 + D-day 알림**
- 🛡️ **오프라인 우선 + 로컬 암호화** (프라이버시)

### 현실적 위치 (냉정한 평가)
- **인지도**: comcbt/맞추다 대비 신생 = **초기 0**. 이게 가장 큰 벽.
- **콘텐츠 양**: 16,653문항 10종목 확보 = 경쟁력 있음(comcbt만큼은 아직 아님).
- **기술력**: AI·게이미피케이션·UI는 **경쟁 우위**. "요즘 앱" 느낌으로 20~30대 공략 가능.
- **결론**: "무료 기출은 comcbt가 이미 다 준다"는 시장에서 **AI 튜터 + 학습경험**으로
  프리미엄 지불 의사를 만드는 게 유일한 승부처.

## 3. 가격 · 수익 전략 (docs/MONETIZATION_POLICY.md 연동)

### 3단 구조 (현행 정책 유지 + 시장 검증)
| 등급 | 가격 | 제공 | 시장 근거 |
|---|---|---|---|
| **무료** | ₩0 | 기출 10% + AI 5회/일 + 배너광고 | comcbt 무료에 대응, 유입 장치 |
| **프리미엄(월)** | ₩4,900/월 | 전 문항·해설·AI 무제한, 광고 제거 | 맞추다 프리미엄과 동급 체감가 |
| **평생(Lifetime)** | ₩79,000 | 영구 프리미엄 | 자격증=단기목표 특성상 "한 번 결제" 선호 |

### 전략적 조정 제안
1. **"AI 무제한"을 프리미엄의 간판 혜택으로** — 경쟁자에 없는 기능이라 지불 명분이 뚜렷.
2. **합격 시즌(시험 2~4주 전) 한정 할인** — 자격증 시장은 시험일정에 수요가 몰림.
3. **평생 결제를 밀어라** — 자격증은 "합격하면 끝"이라 월구독 이탈이 빠름.
   평생 결제(₩79,000)가 LTV·현금흐름에 유리. 실제 매출 대부분이 여기서 나올 것.
4. **무료 이탈 방지**: 무료에서도 게이미피케이션·오답노트는 열어 습관 형성 후 전환 유도.

### 손익 관점
- AI 비용(Cerebras)이 변동비의 핵심 → **무료 5회/일 상한 + BYOK 옵션**으로 원가 방어(이미 구현).
- 배너 광고(AdMob)는 무료 유저 최소 수익화용. 학습 몰입 해치지 않게 위치 신중히.

## 4. 마케팅 · 판매(GTM) 전략

### Phase 0 — 출시 전 (지금)
- 스토어 등록 자산 준비: 아이콘, 스크린샷 5~8장, 소개영상, 키워드.
- **ASO(앱스토어 최적화)** 핵심 키워드: `전기기사`, `전기산업기사`, `소방설비기사`,
  `CBT 기출문제`, `자격증 AI`, `산업안전기사`. → 앱 제목/설명에 자연 삽입.
- 베타 테스터 20~50명(License Testing) 확보 → 초기 리뷰·별점 확보.

### Phase 1 — 출시 초기 (0~3개월): "무료로 씨 뿌리기"
- **완전 무료 체험 강조** + AI 튜터를 훅으로. "AI가 오답을 설명해주는 유일한 앱".
- 채널: 전기기사 준비 카페/오픈채팅, 유튜브 전기기사 강사 협업(제휴 코드),
  인스타/스레드 숏폼("AI한테 물어보며 공부").
- comcbt/맞추다 리뷰의 불만(UI 구식, 해설 유료)을 저격하는 콘텐츠 마케팅.

### Phase 2 — 성장기 (3~12개월): "전환·리텐션"
- 합격 후기 UGC 캠페인(합격 인증 → 리워드).
- 시험 시즌 타겟 푸시(D-30/D-7 알림 + 프리미엄 할인).
- 종목 확장(정보처리·건축 등)으로 신규 유입 풀 확대.

### Phase 3 — 확장기: B2B/제휴
- 학원·직업훈련기관 단체 라이선스(평생권 대량).
- 통신판매업 사업자 보유 → **자사몰/스마트스토어에서 평생권 판매**도 병행 가능
  (스토어 인앱결제 수수료 30% 회피 경로. 단, 앱 내 외부결제 유도는 스토어 정책 위반 주의).

## 5. 마켓 등록 실행 가이드 (⭐ 강력 권장)

> 통신판매업 사업자를 보유하고 계시므로, **정식 스토어 등록을 강력히 권장**합니다.
> APK 직접 배포보다 신뢰도·유입·결제 인프라 면에서 압도적입니다.

### 5-1. Google Play (우선순위 1)
1. **Play Console 개발자 계정** 등록 (일회성 $25).
2. 사업자 정보 등록(통신판매업 신고번호 포함) → 유료앱/인앱결제 활성화.
3. 앱 서명 키(이미 `android/release-key.jks` 보유) → Play App Signing 등록.
4. 스토어 등록정보: 제목/간단설명/자세한설명(ASO 키워드), 스크린샷, 아이콘, 개인정보처리방침 URL.
5. **콘텐츠 등급, 데이터 안전(Data Safety)** 설문 — 로컬저장/네트워크 사용 정직 기재.
6. **인앱결제(구독+평생권)** 상품 등록 → `billing.js` 서버 검증 연동.
7. 내부테스트 → 비공개테스트 → 프로덕션 순 출시.
8. **라이선스 테스터**에 `designssir@gmail.com` 등록 → 무료로 유료상품 검수.

### 5-2. Apple App Store (우선순위 2, iOS 확장 시)
1. Apple Developer Program(연 $99).
2. 현재 코드베이스는 Flutter라 iOS 빌드 가능하나, **iOS 빌드/서명 환경 별도 필요**.
3. App Store 심사가 Android보다 엄격 — 관리자 백도어/외부결제 유도는 반려 사유이니 주의.

### 5-3. 등록 전 체크리스트
- [ ] 개인정보처리방침 URL(웹 호스팅) — 필수
- [ ] 이용약관 / 환불정책(통신판매업 표준) 명시
- [ ] 저작권: 기출문제 해설의 저작권 출처 확인(comcbt 사례처럼 분쟁 소지 관리)
- [ ] 관리자 모드는 스토어 심사 시 노출되지 않도록 숨김 진입 유지(현재 설정 하위 메뉴)
- [ ] Cloudflare 백엔드 실배포 + `store_url` 을 version.json에 기입(자동 업데이트 연동)
