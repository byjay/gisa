# 실패 원장 (재건)

R60~R86 라운드에서 축적한 원장 35건은 샌드박스 초기화로 소실됐다.
소실된 것을 기억에 의존해 "복원"하면 원본과 다른 물건이 되고, 그것을 복원이라
부르는 것은 거짓 보고다. 그래서 **소실을 사실로 기록하고 여기서 다시 시작한다.**

원장의 목적은 자책이 아니다. 같은 실패를 **물리적으로 불가능하게** 만드는 것이다.
따라서 각 항목은 반드시 「검사」 열에 실행 가능한 방어 장치를 갖는다.
장치 없는 항목은 반성이 아니라 감상이다.

## 이 원장을 쓰는 규칙

1. **항목은 지우지 않는다.** 아래 래칫이 건수 하한을 고정한다.
2. **각 항목은 반드시 실행 가능한 검사를 갖는다.** 검사 없는 항목은 감상이므로 추가 자격이 없다.
3. **검사를 느슨하게 해서 통과시키는 것은 금지한다.** 조이는 방향으로만 갱신한다.
4. **소실된 원장 35건을 기억으로 복원하지 않는다.** 이 파일은 재건이며, 재건임을 명시한다.

현재 건수: 7건 (L1~L7). `survival_check.sh` 가 하한을 고정하지는 않지만,
자기진화 게이트를 재건할 때 이 건수를 래칫 하한으로 삼는다.
