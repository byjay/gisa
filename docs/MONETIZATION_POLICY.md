# MONETIZATION_POLICY.md — Gisaclub 수익모델 명문화 (Q93)

> 문서 버전 v1.0 · 최종 갱신: R55
> 이 문서는 Gisaclub의 수익 구조·과금 정책·무료/유료 경계를 공식적으로 정의한다.
> 스토어 등록(데이터 안전/구독 고지), 앱 내 결제 UI, 서버 권한(Entitlement) 판정의 단일 기준 문서.

---

## 1. 수익모델 개요 — 프리미엄 프리(Freemium) + 선택적 광고

Gisaclub은 **완전 무료 사용 가능**을 기본으로 하되, 헤비 유저 대상 **프리미엄 구독**으로 수익을 낸다.
학습 앱 시장 조사(맞추다 해설 유료 ~18,000원 / 오르조 3일 후 유료) 대비,
**핵심 학습 루프(풀기→채점→해설→오답복습)는 무료로 유지**하여 진입 장벽을 낮추고
편의·고급 기능에서 과금하는 구조로 차별화한다.

### 1.1 3-티어 구조

| 티어 | 가격(안) | 대상 |
|------|---------|------|
| **무료 (Free)** | ₩0 | 모든 사용자, 광고 노출(선택적) |
| **프리미엄 (Premium)** | 월 ₩4,900 / 연 ₩39,000(약 33% 할인) | 시험 임박·집중 학습자 |
| **평생 (Lifetime)** | ₩79,000 (1회) | 장기·다자격증 준비자 |

> 가격은 스토어 심사·A/B 테스트로 조정 가능. 이 표는 정책 기준선이며 실제 가격은
> `lib/screens/premium_screen.dart`의 플랜 정의와 동기화한다.

## 2. 무료 / 유료 경계 (Feature Gating)

서버(Cloudflare) 및 앱(`EntitlementService`)이 공동으로 판정한다.

| 기능 | 무료 | 프리미엄 |
|------|------|---------|
| 회차별·과목별 기출 풀이 | **문항의 10%**(무료 미리보기) | 전 문항 무제한 |
| 자동 채점 + 정답 | ✅ (푼 문항 한정) | ✅ |
| 해설·1:1 강의(이론 슬라이드) | 미리보기 일부 | 전체 |
| 오답노트 자동 축적·복습(SRS) | ✅ | ✅ |
| AI 튜터(볼트쌤) | **1일 5회** | 무제한 |
| 기출빈도 상세(등급·예상출제) | 요약만 | 상세 전체 |
| 속독 답외우기(자동재생·셀프테스트) | 카드 일부 | 전체 |
| 합격 예측·주간 리포트·히트맵 | ✅ | ✅ + 심화 |
| 광고 | 노출 | **제거** |

> **원칙**: 무료 사용자도 "학습이 실제로 되는" 경험을 하도록 핵심 루프는 막지 않는다.
> 과금 포인트는 ① 분량(10%→전체) ② AI 사용량 ③ 광고 제거 ④ 고급 분석이다.

### 2.1 상수 (서버 `wrangler.toml` vars와 동기화)
- `FREE_QUESTION_RATIO = 0.10` — 무료 노출 문항 비율
- `FREE_AI_DAILY_LIMIT = 5` — 무료 AI 1일 한도

## 3. 광고 정책 (선택적)

- **형식**: 배너(하단) + 전면(모의고사 결과 화면, 세션당 1회 이하).
- **금지**: 문제 풀이 중 인터랙션을 가리는 전면 광고, 오답/해설 화면 광고.
- **제거**: 프리미엄/평생 구독 시 전 광고 제거.
- **SDK**: `google_mobile_ads`(도입 시). 현재 앱은 광고 미탑재 상태 —
  광고 도입은 별도 릴리즈에서 옵트인.
- **아동/개인정보**: 시험 준비 앱 특성상 성인 대상. 비개인화 광고 옵션 제공.

---

## 4. 결제 처리 · 영수증 검증

- **스토어**: Google Play 인앱결제(구독 SKU: `premium_monthly`, `premium_yearly`, `lifetime`).
- **검증**: 클라이언트 구매 → 서버(`/v1/billing/verify`)가 Google Play Developer API로
  **서버 사이드 영수증 검증** 후 D1 `purchases`/`entitlements` 갱신 → 앱이 서버 권한 동기화.
- **복원**: 기기 변경 시 스토어 계정 기준 구매 복원(restorePurchases).
- **환불**: 스토어 정책 준수. 서버 웹훅으로 환불 감지 시 entitlement 회수.

---

## 5. 개인정보 · 데이터 안전 (스토어 고지 연동)

- 학습기록·오답노트는 **기기 로컬 암호화 저장**(HiveAesCipher, `SecureBoxService`).
- 서버 전송 데이터: 인증 토큰, 구매 영수증, AI 질의(선택). 문제 콘텐츠 열람 로그.
- **판매/제3자 공유 없음**. AI 질의는 응답 생성 목적으로만 사용.
- 오류 로그는 **로컬에만** 저장(외부 크래시 SaaS 미사용, `CrashLogger`).
