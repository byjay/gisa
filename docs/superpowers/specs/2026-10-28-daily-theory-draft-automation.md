# 일일 이론 글 초안 자동 생성

## 의도

사용자 요청에 따라 자격증 종목·과목마다 하루 세 개의 이론 글 후보를 서버에서 자동 준비한다. 네이버 블로그의 공식 게시 자동화 경로가 확인되지 않았고 네이버는 자동 대량 게시와 기계적 대량 생성 콘텐츠를 제한하므로, 공개 게시 대신 관리자 검토 대기 초안까지만 만든다.

## 목표

- Cloudflare Worker Cron이 한국 시간 기준 하루 한 번 최대 세 개의 초안을 만든다.
- 주제는 R2 공개 카탈로그의 자격증명·과목명에서 순환 선택한다.
- 프롬프트에는 과목명과 주제명만 넣고 문제 본문, 정답, 해설, 교재 원문은 넣지 않는다.
- 결과는 관리자 인증 API로만 읽고 검토/수정/승인/반려할 수 있다.
- 날짜/슬롯 유일키와 원자적 상태 변경으로 Cron 재시도 중복 생성을 막는다.
- 검색어만 바꾼 반복 글 대신, 독립적인 개념 설명·직접 만든 예시·검토 메모가 있는 초안을 요구한다.

## 경계와 제외

- 네이버 블로그나 카페에 자동 로그인·비공개 엔드포인트·쿠키를 이용해 자동 발행하지 않는다.
- 자동화는 공개 게시를 하지 않는다. 초안을 승인해도 Naver 게시 API가 확인되지 않으므로 복사 가능한 검토 결과만 반환한다.
- 모든 초안은 사실 검토 전이며 검색 노출이나 정확성을 보증하지 않는다.
- 모델에 학습 자료 본문을 전달하지 않으며 응답 원문·비밀값을 로그에 기록하지 않는다.
- 배포, D1 원격 마이그레이션, 실제 계정 설정은 이번 구현 범위에서 제외한다.

## 설계 선택

Worker Cron + D1 비공개 초안 큐 + 기존 관리자 인증을 사용한다. D1의 날짜·슬롯 유일키와 `queued → generating → review` 전이는 중복 실행을 막고, 실패는 해당 슬롯의 상태로 남긴다. 생성에는 기존 서버 전용 AI 공급자 설정을 사용하고, 키가 없으면 외부 호출 없이 명시적으로 비활성 처리한다.
