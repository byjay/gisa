# 제1장 벡터 해석 (기초 도구)

## 1.1 벡터의 내적과 외적
- **내적**: A·B = |A||B|cosθ → 스칼라 (일 W = F·d)
- **외적**: A×B = |A||B|sinθ n → 벡터 (힘 F = IL×B)

## 1.2 미분 연산자 (∇, nabla)
| 연산 | 표기 | 의미 | 결과 |
|---|---|---|---|
| 기울기 | grad V = ∇V | 스칼라의 최대 증가 방향 | 벡터 |
| 발산 | div A = ∇·A | 단위체적당 유출량(솟음) | 스칼라 |
| 회전 | rot A = ∇×A | 소용돌이 정도 | 벡터 |
| 라플라시안 | ∇²V | div(grad V) | 스칼라 |

**빈출 항등식**:
- ∇×(∇V) = 0 (기울기의 회전은 항상 0)
- ∇·(∇×A) = 0 (회전의 발산은 항상 0)
- **발산 정리(가우스)**: ∮ₛ A·dS = ∫ᵥ (∇·A) dv — 면적분↔체적적분
- **스토크스 정리**: ∮ᴄ A·dl = ∫ₛ (∇×A)·dS — 선적분↔면적분

# 제2장 진공 중의 정전계 ★★★★★ (회당 3문항)

## 2.1 쿨롱의 법칙
두 점전하 사이의 힘:

**F = Q₁Q₂ / (4πε₀r²) [N]**,  1/(4πε₀) = 9×10⁹

- ε₀ = 8.855×10⁻¹² F/m (진공 유전율)
- 같은 부호: 반발력, 다른 부호: 흡인력

## 2.2 전계의 세기 E
**E = Q / (4πε₀r²) [V/m]**, F = QE

**형상별 전계 공식 (10년간 최다 빈출 — 반드시 암기)**:
| 대전체 | 전계의 세기 | 거리 의존성 |
|---|---|---|
| 점전하 | E = Q/(4πε₀r²) | 1/r² |
| 무한장 직선(선전하 λ) | E = λ/(2πε₀r) | 1/r |
| 무한 평면(면전하 σ) | E = σ/(2ε₀) | 거리 무관 |
| 두 평행 무한평면 사이 | E = σ/ε₀ | 거리 무관 |
| 구도체 외부 | E = Q/(4πε₀r²) | 1/r² |
| 구도체 표면 | E = Q/(4πε₀a²) | 최대 |
| **도체구 내부** | **E = 0** | - |
| 균일 대전 유전체구 내부 | E = Qr/(4πε₀a³) | r에 비례 |
| 동축원통(내외도체 사이) | E = λ/(2πε₀r) | 1/r |

**전기력선의 성질(빈출)**:
1. 양전하에서 나와 음전하에서 끝남
2. 도체 표면에 수직으로 출입
3. 서로 교차하지 않음
4. 전기력선 밀도 = 전계의 세기
5. 도체 내부에는 존재하지 않음
6. Q[C]에서 나오는 전기력선 수 = Q/ε₀개, 전속선 수 = Q개

## 2.3 전위 V ★★★
**V = Q/(4πε₀r) [V]** (점전하, 무한원점 기준)

- V = -∫E·dl (전계를 거슬러 단위 전하를 옮기는 일)
- **E = -grad V = -∇V** (전위경도의 음의 방향) ← 빈출
- 등전위면과 전기력선은 직교
- 폐회로 일주 시 일 = 0 (보존장): ∮E·dl = 0, ∇×E = 0

**전위 공식**:
| 형상 | 전위 |
|---|---|
| 점전하 | V = Q/(4πε₀r) |
| 구도체(반지름 a) | V = Q/(4πε₀a) |
| 무한장 직선 | 두 점 간 전위차 V = λ/(2πε₀)·ln(r₂/r₁) |
| 전기 쌍극자 | V = M cosθ/(4πε₀r²), M=Qδ [C·m] |

**전기 쌍극자(빈출)**: 전계 E = M/(4πε₀r³)·√(1+3cos²θ)
- θ=0°일 때 최대, θ=90°일 때 최소 — r³에 반비례

## 2.4 가우스 법칙 ★★★
**∮ E·dS = Q/ε₀** (폐곡면을 나오는 전기력선 총수)
**∮ D·dS = Q** (전속은 매질 무관)

미분형: ∇·D = ρ, ∇·E = ρ/ε₀

**포아송 방정식**: ∇²V = -ρ/ε₀ ← 빈출 (전하분포로부터 전위)
**라플라스 방정식**: ∇²V = 0 (전하가 없는 곳)

# 제3장 진공 중의 도체계와 정전용량 ★★★

## 3.1 정전용량 공식 총정리 (암기 필수)
| 도체계 | 정전용량 C |
|---|---|
| 구도체(반지름 a) | 4πε₀a |
| 동심구(a<b) | 4πε₀ab/(b-a) |
| 평행판(면적 S, 간격 d) | ε₀S/d |
| 동축케이블(단위길이) | 2πε₀/ln(b/a) |
| 평행 왕복도선(단위길이) | πε₀/ln(d/a) |

## 3.2 콘덴서 접속
- 병렬: C = C₁+C₂ (전압 동일)
- 직렬: C = C₁C₂/(C₁+C₂) (전하 동일)
- **직렬 시 전압 분배**: V₁ = C₂V/(C₁+C₂) — 용량에 반비례 배분
- 내압이 같은 콘덴서 직렬 시: 용량 작은 것이 먼저 파괴

## 3.3 정전 에너지 ★
**W = ½CV² = ½QV = Q²/2C [J]**

- **단위 체적당 에너지(에너지 밀도)**: w = ½εE² = D²/2ε = ½ED [J/m³] ← 빈출
- **정전 흡인력(단위 면적당)**: f = ½εE² = σ²/2ε [N/m²] — 에너지 밀도와 같은 꼴

## 3.4 전위계수·용량계수(가끔 출제)
- V₁ = P₁₁Q₁ + P₁₂Q₂ (전위계수 P: 대칭 Pᵢⱼ=Pⱼᵢ, Pᵢᵢ>0)
- 용량계수 qᵢᵢ>0, 유도계수 qᵢⱼ≤0

# 제4장 유전체 ★★★★★ (회당 2.4문항)

## 4.1 분극 (Polarization)
- 유전체를 전계 내에 두면 내부에 **구속전하**가 유도됨 = 분극
- **분극의 세기**: P = D - ε₀E = ε₀(εr-1)E = χE [C/m²]
  - χ = ε₀(εr-1): 분극률
- 분극 종류: 전자분극(모든 유전체), 이온분극, 배향(쌍극자)분극(극성 분자)
- **분극 전하량**: Q' = Q(1 - 1/εr) ← 2022년 기출

## 4.2 유전체 삽입 효과 (빈출 비교표)
| 조건 | E | D | C | V | W |
|---|---|---|---|---|---|
| **전하 Q 일정**(전원 분리) | 1/εr배 | 불변 | εr배 | 1/εr배 | 1/εr배 감소 |
| **전압 V 일정**(전원 연결) | 불변 | εr배 | εr배 | 불변 | εr배 증가 |

## 4.3 유전체 경계조건 ★★★ (매년 출제 수준)
경계면에 진전하가 없을 때:
1. **전속밀도의 법선(수직)성분 연속**: D₁cosθ₁ = D₂cosθ₂
2. **전계의 접선(수평)성분 연속**: E₁sinθ₁ = E₂sinθ₂
3. **굴절 법칙**: tanθ₁/tanθ₂ = ε₁/ε₂

**핵심 결론(빈출)**:
- ε₁ > ε₂이면 θ₁ > θ₂ (유전율 큰 쪽에서 굴절각 큼)
- 전속선은 유전율이 **큰** 쪽으로 모임
- 전기력선은 유전율이 **작은** 쪽으로 모임
- 경계면에 수직 입사 시: D 연속, E 불연속
- **맥스웰 응력**: 경계면에는 유전율이 큰 쪽에서 작은 쪽으로 힘이 작용(인장력) ← 2022년 기출
  - f = ½(1/ε₂ - 1/ε₁)D² [N/m²] (수직 입사)

## 4.4 유전체 콘덴서 조합
- 평행판에 유전체를 **수평(직렬)** 적층: C = S/(d₁/ε₁ + d₂/ε₂)
- 평행판에 유전체를 **수직(병렬)** 배치: C = (ε₁S₁ + ε₂S₂)/d

## 4.5 패러데이관 성질(빈출 지문)
- 패러데이관 내 전속수 일정, 양단에 정·부의 단위 전하 존재
- 진전하가 없는 점에서 연속, 밀도 = 전속밀도
- 패러데이관 수 = 전속 수 = Q개

# 제6장 전류 ★★★

## 6.1 전류와 저항
- I = Q/t = nevS (n: 전자밀도, v: 이동속도)
- **R = ρl/S = l/(kS)** (ρ: 고유저항 [Ω·m], k: 도전율 [S/m])
- 전류밀도: J = I/S = kE = nev [A/m²] — **옴의 법칙 미분형 J = kE** ← 빈출

## 6.2 저항과 정전용량의 관계 (빈출 공식)
**RC = ρε** → R = ρε/C
- 예: 동축케이블 절연저항, 접지저항 계산에 활용
- 반구형 접지극 접지저항: R = ρ/(2πa)

## 6.3 열전현상 ★ (자주 출제)
| 효과 | 내용 |
|---|---|
| **제벡 효과** | 서로 다른 두 금속 접합, 온도차 → 열기전력 (열전대 온도측정) |
| **펠티에 효과** | 서로 다른 두 금속에 전류 → 접합부 열 흡수/발생 (전자냉동) |
| **톰슨 효과** | **같은** 금속에서 온도차 있는 부분에 전류 → 열 흡수/발생 |
| 홀 효과 | 도체에 전류+자계 → 수직 방향 전위차 |
| 핀치 효과 | 액체 도체에 전류 → 중심으로 수축 |

# 제7장 진공 중의 정자계 ★★★★ (회당 1.8문항)

## 7.1 정전계와 정자계 대응(쿨롱의 자기법칙)
- F = m₁m₂/(4πμ₀r²) [N], μ₀ = 4π×10⁷ H/m
- 자계의 세기: H = m/(4πμ₀r²) [AT/m], F = mH
- 자위: U = m/(4πμ₀r) [A]

## 7.2 비오-사바르 법칙 ★★★
**dH = I dl sinθ/(4πr²) [AT/m]**

**형상별 자계 공식 (최다 빈출 암기표)**:
| 전류 형상 | 자계의 세기 H |
|---|---|
| 무한장 직선 | H = I/(2πr) |
| 유한 직선(양끝각 θ₁,θ₂) | H = I/(4πr)·(cosθ₁+cosθ₂) |
| **원형 코일 중심**(반지름 a, N회) | H = NI/(2a) |
| 원형 코일 축상 x | H = a²I/(2(a²+x²)^(3/2)) |
| 무한장 솔레노이드 내부 | H = nI (n: 단위길이당 권수), 외부 H=0 |
| 환상 솔레노이드 내부 | H = NI/(2πr), 외부 H=0 |
| **정사각형(한 변 l) 중심** | H = 2√2 I/(πl) |
| 정삼각형(한 변 l) 중심 | H = 9I/(2πl) |
| 정육각형(한 변 l) 중심 | H = √3 I/(πl) |
| 반원형 코일 중심 | H = I/(4a) |

## 7.3 암페어(앙페르) 주회적분 법칙
**∮ H·dl = NI** — 폐곡선을 쇄교하는 전류 총합
- 미분형: ∇×H = J

## 7.4 전자력
- **플레밍 왼손 법칙**(전동기): F = BIl sinθ [N], F = Il×B
- 평행 왕복도선 간 힘: **F = μ₀I₁I₂/(2πd) = 2I₁I₂/d ×10⁻⁷ [N/m]**
  - 같은 방향 전류: 흡인력 / 반대 방향: 반발력 ← 빈출
- **로렌츠 힘**: F = q(E + v×B)
- 자계 중 전자 운동: 원운동, 반지름 r = mv/(qB), 주기 T = 2πm/(qB) (속도 무관) ← 빈출

## 7.5 자기 쌍극자·판자석
- 자기 모멘트 M = ml [Wb·m]
- 회전력(토크) T = M×H = MHsinθ = mlHsinθ ← 빈출
- 판자석 전위: U = M ω/(4πμ₀) (ω: 입체각)

# 제8장 자성체와 자기회로 ★★★★★ (회당 3.0문항 — 1위)

## 8.1 자성체 분류 (매년 출제 수준)
| 종류 | 비투자율 | 자화율 | 예 |
|---|---|---|---|
| **강자성체** | μr ≫ 1 | χ ≫ 0 | 철, 니켈, 코발트 |
| 상자성체 | μr > 1 | χ > 0 | 알루미늄, 백금, 산소, 텅스텐 |
| **반자성체** | μr < 1 | χ < 0 | 구리, 은, 비스무트, 물, 금 |
| 반강자성체 | 인접 자기모멘트 반대 배열 | | |

**강자성체 3대 특징(빈출 지문)**: ① 자구(磁區) 존재 ② 히스테리시스 특성 ③ 포화 특성

## 8.2 자화의 세기
**J = B - μ₀H = μ₀(μr-1)H = χH [Wb/m²]**
- J = B(1 - 1/μr)
- 자화율 χ = μ₀(μr-1)

## 8.3 히스테리시스 곡선 (B-H 곡선) ★★★
- **종축: 자속밀도 B, 횡축: 자계 H**
- 종축과 만나는 점: **잔류자기 Br** / 횡축과 만나는 점: **보자력 Hc**
- **히스테리시스 손실**: Ph = ηf Bm^1.6 [W/m³] (주파수에 비례) ← 빈출
- **영구자석**: 잔류자기·보자력 모두 큼 (곡선 면적 큼)
- **전자석(규소강판)**: 잔류자기 크고 보자력 작음 (면적 작음)
- **와류손**: Pe = η(tfBm)² — 두께², 주파수², 자속밀도²에 비례
- **바크하우젠 효과**: B-H 곡선에서 자속밀도가 계단상으로 불연속 증가하는 현상 ← 2022년 기출
- **큐리점(온도)**: 강자성 → 상자성으로 변하는 온도 (철: 약 770℃)
- **자기여자 효과(자기 애프터 이펙트)**: 자화가 시간적으로 늦는 현상
- **자왜현상**: 자화 시 자성체 길이·체적 변화

## 8.4 자기회로 (옴의 법칙 유추) ★★★
| 전기회로 | 자기회로 |
|---|---|
| 기전력 E [V] | 기자력 F = NI [AT] |
| 전류 I [A] | 자속 φ [Wb] |
| 저항 R [Ω] | 자기저항 Rm = l/(μS) [AT/Wb] |
| 도전율 k | 투자율 μ |

**φ = NI/Rm = μSNI/l [Wb]** ← 빈출 (2022년: φ = μSNI/l)

- 공극(에어갭)이 있는 자기회로: Rm = l/(μS) + lg/(μ₀S)
  - 공극 시 자기저항 비: 1 + (lg·μr/l) 배 증가 ← 빈출
- **자기회로에는 전기회로의 줄손실에 해당하는 손실이 없음** (누설자속은 존재)

## 8.5 자성체 경계조건
1. B의 법선성분 연속: B₁cosθ₁ = B₂cosθ₂
2. H의 접선성분 연속: H₁sinθ₁ = H₂sinθ₂
3. tanθ₁/tanθ₂ = μ₁/μ₂
- 자속은 투자율 큰 쪽으로 모임

## 8.6 감자력(자기차폐 관련)
- 감자력 H' = (N/μ₀)J (N: 감자율)
- 구자성체 N = 1/3, 가늘고 긴 막대 N→0, 환상 철심 N=0 ← 빈출
- 자기차폐: 투자율 큰 강자성체 중공구로 둘러쌈

# 제9장 전자유도 ★★

## 9.1 패러데이 법칙 & 렌츠 법칙
**e = -N dφ/dt [V]**
- 렌츠 법칙: 유도 기전력은 자속 변화를 **방해**하는 방향 (음부호의 의미)
- 노이만 법칙: 위 식 전체

## 9.2 운동 기전력
**e = Blv sinθ [V]** (플레밍 오른손 법칙 — 발전기)
- 자계 내 회전 도체: e = Bωl²/2

## 9.3 표피효과 ★ (빈출)
- 주파수↑, 도전율↑, 투자율↑ → 표피효과 심해짐
- **침투깊이**: δ = 1/√(πfμk) [m]
  - δ 작을수록 표피효과 큼
- 와전류: 자속 변화를 방해하는 방향으로 도체 내 소용돌이 전류, ∇×J = -k(∂B/∂t)

# 제10장 인덕턴스 ★★★★ (회당 1.3문항)

## 10.1 자기 인덕턴스
**L = Nφ/I [H]**, e = -L(dI/dt)

**형상별 인덕턴스(암기표)**:
| 형상 | L |
|---|---|
| 환상 솔레노이드 | L = μSN²/l = μπa²N²/(2πr) |
| 무한장 솔레노이드(단위길이) | L = μSn² |
| 동축케이블 | L = (μ₀/2π)ln(b/a) + μ/(8π) (내부 포함) |
| 평행 왕복도선 | L = (μ₀/π)ln(d/a) + μ/(4π) |
| 직선도체 내부(단위길이) | L = μ/(8π) — 굵기 무관 ← 빈출 |

**중요**: L ∝ N² (권수 제곱에 비례) ← 2022년 기출: N을 구하는 역산 문제

## 10.2 상호 인덕턴스 ★★★
**M = k√(L₁L₂)** (k: 결합계수 0≤k≤1)
- 환상 철심 두 코일(누설 없음, k=1): M = μSN₁N₂/l
- **M = L₁·(N₂/N₁)** ← 2022년 기출: L₁=4H, N₁=100, N₂=400 → M=16H
- 유도 기전력: e₂ = -M(dI₁/dt)

## 10.3 합성 인덕턴스
- 직렬 가동결합: L = L₁+L₂+2M
- 직렬 차동결합: L = L₁+L₂-2M
- (가동-차동)/4 = M

## 10.4 자기 에너지
**W = ½LI² [J]**, 상호결합 시 W = ½L₁I₁²+½L₂I₂²±MI₁I₂
- 단위 체적당: w = ½μH² = B²/2μ = ½BH [J/m³]
- 흡인력: f = B²/(2μ₀) [N/m²] (전자석)

# 제11장 전자계(맥스웰 방정식·전자파) ★★★

## 11.1 변위전류 ★ (빈출)
**iD = ∂D/∂t = ε(∂E/∂t) [A/m²]**
- 유전체(콘덴서) 내부를 흐르는 전류 — 자계를 발생시킴
- 콘덴서에 교류 인가 시: Id = ωεE·S = ωC V ← 2022년 기출

## 11.2 맥스웰 방정식 4형식 (매년 출제 수준)
| 방정식 | 미분형 | 의미 |
|---|---|---|
| 암페어-맥스웰 | ∇×H = J + ∂D/∂t | 전류+변위전류 → 회전 자계 |
| 패러데이 | ∇×E = -∂B/∂t | 자속 변화 → 회전 전계 |
| 가우스(전기) | ∇·D = ρ | 전하 → 전속 발산 |
| 가우스(자기) | ∇·B = 0 | 고립 자극(N/S 단독) 없음 |

## 11.3 전자파 ★★
- **전파속도**: v = 1/√(με) = 3×10⁸/√(εrμr) [m/s]
- **고유(파동) 임피던스**: η = E/H = √(μ/ε) = 377√(μr/εr) [Ω]
  - 진공: 377Ω = 120π
  - 예제(2022): εr=81, μr=1 → η = 377/9 ≒ 41.9Ω
- **포인팅 벡터**: P = E×H [W/m²] — 전자파 진행 방향의 단위면적당 전력
  - P = EH = E²/377 (진공)
- 전자파 성질: E⊥H, 진행방향은 E×H, E와 H는 동위상, 횡파(TEM)

## 11.4 전송 관련
- 위상속도, 군속도: vp·vg = v²
