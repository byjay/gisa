# [회로이론편]

# 제1장 교류회로 기초 ★★★

## 1.1 파형의 값 (초빈출 암기표)
| 파형 | 실효값 | 평균값 | 파형률 | 파고율 |
|---|---|---|---|---|
| **정현파** | Vm/√2 | 2Vm/π | 1.11 | 1.414 |
| 전파정류 | Vm/√2 | 2Vm/π | 1.11 | 1.414 |
| 반파정류 | Vm/2 | Vm/π | 1.57 | 2 |
| **구형파** | Vm | Vm | 1 | 1 |
| 삼각파 | Vm/√3 | Vm/2 | 1.155 | 1.732 |

- 파형률 = 실효값/평균값, 파고율 = 최대값/실효값

## 1.2 R-L-C 소자
- L: 전류가 전압보다 90° 뒤짐(지상), XL = ωL
- C: 전류가 90° 앞섬(진상), Xc = 1/ωC
- 직렬 임피던스 Z = R + j(XL - Xc)

## 1.3 공진 ★★
- 직렬공진: XL = Xc, **Z 최소·전류 최대**, f₀ = 1/(2π√LC)
- **선택도(첨예도) Q = (1/R)√(L/C) = 공진 시 전압 확대비**
- 병렬공진: 어드미턴스 최소, 전류 최소

## 1.4 교류전력 ★★★
- 유효 P = VIcosθ [W], 무효 Pr = VIsinθ [Var], 피상 Pa = VI [VA]
- **P = I²R = V²R/(R²+X²)**
- 복소전력: S = V̄I = P + jPr
- **최대 전력 전달: 부하저항 = 내부저항, Pmax = V²/4R** ← 빈출
- 2전력계법: P = W₁+W₂, Pr = √3(W₁-W₂), **한쪽이 0이면 역률 0.5** ← 빈출

# 제2장 3상 회로 ★★★★ (회당 1.4문항)

## 2.1 결선 변환
- **Y↔Δ: 선전압·선전류·임피던스 관계**
  - Y결선: V선 = √3 V상∠+30°, I선 = I상
  - Δ결선: V선 = V상, I선 = √3 I상∠-30°
- **Δ→Y 변환: 임피던스 1/3배** (평형 시) ← 초빈출
- Y→Δ: 3배

## 2.2 3상 전력
**P = √3 VL IL cosθ = 3 V상 I상 cosθ**
- V결선 출력 = √3 P₁ (이용률 86.6%)

## 2.3 불평형·회전자계
- 비대칭 3상 전류 → 타원 회전자계
- n상 교류: 위상차 2π/n, 환상결선 시 선전류 = 2sin(π/n)×상전류

# 제3장 비정현파·왜형파 ★★
- 푸리에 급수: 직류분 + 기본파 + 고조파
- **실효값 = √(각 파 실효값 제곱합)**
- **왜형률 THD = 고조파 실효값/기본파 실효값** ← 빈출
- 대칭성: 반파대칭(홀수 고조파만), 우함수(cos항), 기함수(sin항)
- 3고조파: Δ결선 내 순환, 중성선에 흐름

# 제4장 과도현상 ★★★★ (회당 1.1문항)

## 4.1 R-L 직렬 (직류 인가)
- i(t) = (E/R)(1 - e^(-Rt/L))
- **시정수 τ = L/R** — 최종값의 63.2% 도달 시간 ← 초빈출
- 초기 전류 상승률: E/L

## 4.2 R-C 직렬
- 충전: i(t) = (E/R)e^(-t/RC), **τ = RC**
- 시정수에서 충전전압 = 63.2%, 방전 시 36.8%

## 4.3 R-L-C 직렬 (진동 조건) ★
- **R² > 4L/C: 비진동(과제동)**
- **R² = 4L/C: 임계제동**
- **R² < 4L/C: 진동(부족제동)** ← 초빈출
- L·C 회로: 무한 진동, f = 1/(2π√LC)

# 제5장 라플라스 변환 ★★★★ (회당 1.3문항)

## 5.1 기본 변환표 (초빈출)
| f(t) | F(s) |
|---|---|
| δ(t) 임펄스 | 1 |
| u(t) 단위계단 | 1/s |
| t | 1/s² |
| e^(-at) | 1/(s+a) |
| sinωt | ω/(s²+ω²) |
| cosωt | s/(s²+ω²) |
| t·e^(-at) | 1/(s+a)² |
| e^(-at)sinωt | ω/((s+a)²+ω²) |

## 5.2 정리 ★★★
- **초기값 정리: f(0) = lim(s→∞) sF(s)**
- **최종값 정리: f(∞) = lim(s→0) sF(s)** ← 초빈출
- 시간추이: f(t-a) ↔ e^(-as)F(s)
- 복소추이: e^(-at)f(t) ↔ F(s+a)
- 부분분수 전개로 역변환

# 제6장 2단자망·4단자망 ★★★★ (회당 1.6문항)

## 6.1 2단자망
- 구동점 임피던스: Z(s), s = jω
- **영점(Z=0, 단락)·극점(Z=∞, 개방)** ← 빈출
- 정저항 회로: **R² = L/C** (주파수 무관 순저항) ← 빈출
- 역회로: Z₁Z₂ = K²

## 6.2 4단자 정수 ★★★
**V₁ = AV₂ + BI₂, I₁ = CV₂ + DI₂**
- **AD - BC = 1**, 대칭이면 A = D
- A: 전압비, B: 임피던스, C: 어드미턴스, D: 전류비
- 직렬 Z 하나: A=1, B=Z, C=0, D=1
- 병렬 Y 하나: A=1, B=0, C=Y, D=1
- L형·T형·π형 조합은 행렬 곱
- **영상 임피던스: Z₀₁ = √(AB/CD), Z₀₂ = √(BD/AC)**, Z₀₁Z₀₂ = B/C ← 빈출
- 전달정수 θ = ln(√AD + √BC)

---

# 제7장 분포정수회로 ★★
- 특성 임피던스 **Z₀ = √(Z/Y) = √(L/C)** (무손실)
- 전파정수 γ = √(ZY) = α + jβ
- **무왜형 조건: RC = LG** ← 빈출
- 무손실: R = G = 0, 속도 v = 1/√(LC)
- 반사계수 = (Z₂-Z₁)/(Z₂+Z₁), 정재파비 = (1+|ρ|)/(1-|ρ|)

# [제어공학편]

# 제8장 전달함수·블록선도 ★★★★★ (회당 3.3문항 — 과목 1위)

## 8.1 전달함수
**G(s) = 출력 라플라스/입력 라플라스** (모든 초기값 0)
- 비례요소 K, 미분요소 Ks, 적분요소 K/s
- 1차 지연: K/(Ts+1), 2차 지연: ωn²/(s²+2δωns+ωn²)
- 부동작 시간: Ke^(-Ls)

## 8.2 블록선도 등가변환 ★★★
- 직렬: G₁G₂, 병렬: G₁±G₂
- **피드백: G/(1±GH)** (부궤환 +) ← 초빈출
- **메이슨 공식**: G = ΣPkΔk/Δ, Δ = 1 - Σ루프이득 + Σ(비접촉 2루프 곱) - …

## 8.3 자동제어계 분류
- 목표값: 정치제어, 추종제어, 프로그램제어, 비율제어
- 제어량: 서보기구(위치·방향), 프로세스제어(온도·압력), 자동조정(전압·주파수)
- **동작**: P(잔류편차 존재), **PI(잔류편차 제거, 정상특성 개선)**, PD(속응성 개선), **PID(최적)** ← 초빈출

# 제9장 과도응답·정상편차 ★★

## 9.1 2차계 응답
G(s) = ωn²/(s² + 2δωn s + ωn²)
- **δ < 1: 부족제동(진동), δ = 1: 임계제동, δ > 1: 과제동** ← 초빈출
- 오버슈트 최대 조건, 감쇠비 = 제2오버슈트/최대오버슈트

## 9.2 정상편차 ★★
- 위치편차상수 Kp = lim G(s), 속도편차 Kv = lim sG(s), 가속도편차 Ka = lim s²G(s) (s→0)
- **계단입력 → 위치편차 1/(1+Kp), 램프입력 → 속도편차 1/Kv**
- **형(type) 판별: G(s)의 원점 극점 수** — 1형은 계단입력 정상편차 0 ← 빈출

---

# 제10장 주파수 응답 ★★
- G(jω)의 크기·위상, 벡터 궤적(나이퀴스트 선도)
- **보드선도**: 이득 20log|G| [dB]
  - 절점 주파수 ω = 1/T에서 -3dB
  - **이득여유 GM, 위상여유 PM > 0 이면 안정** ← 빈출
- 1형 시스템 궤적: ω→0에서 -90° 무한원점

# 제11장 안정도 판별 ★★★ (회당 0.7문항)

## 11.1 루드(Routh) 판별법 ★★★
- **필요조건: 특성방정식 모든 계수 존재·동일 부호**
- 루드표 제1열 부호 변화 수 = 불안정근(우반평면) 수 ← 초빈출
- 예: s³+11s²+2s+40 → 제1열에 음수 → 불안정

## 11.2 나이퀴스트
- (-1, j0)점을 좌측에 두고 감싸지 않으면 안정
- 안정 정보 + 상대 안정도까지 알 수 있음

# 제12장 근궤적 ★★
- 근궤적 수 = max(극점 수, 영점 수) = 특성방정식 차수
- **실수축에서 오른쪽 극+영점 수가 홀수인 구간에 존재** ← 빈출
- 점근선 각도 = (2k+1)π/(p-z), 교차점 σ = (Σ극-Σ영)/(p-z)
- K 범위 문제: 특성방정식에 루드 적용

# 제13장 상태방정식·z변환 ★★

## 13.1 상태방정식
**ẋ = Ax + Bu, y = Cx + Du**
- 특성방정식: |sI - A| = 0 → 고유값 = 극점 ← 초빈출
- **천이행렬 Φ(t) = e^(At) = L⁻¹[(sI-A)⁻¹]**, Φ(0) = I
- 가제어성: [B AB A²B…] 정칙, 가관측성: [C^T A^TC^T…] 정칙

## 13.2 z변환 ★
| f(t) | F(z) |
|---|---|
| δ(t) | 1 |
| u(t) | z/(z-1) |
| e^(-at) | z/(z-e^(-aT)) |
| t | Tz/(z-1)² |

- **s평면 좌반면 ↔ z평면 단위원 내부(안정)** ← 초빈출
- 최종값: lim(z→1)(1-z⁻¹)F(z)

# 제14장 논리회로 ★★ (회당 0.7문항)
- 기본: AND(직렬), OR(병렬), NOT
- **NAND = AND+NOT, NOR = OR+NOT — 유니버설 게이트**
- XOR: 다를 때 1, A⊕B = AB̄+ĀB
- **드모르간: (A+B)' = A'B', (AB)' = A'+B'** ← 초빈출
- 불대수: A+A=A, A·A=A, A+A'B = A+B
- 카르노맵 간소화 빈출
