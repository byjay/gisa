# 제1장 직류기 ★★★★★

## 1.1 구조
**3대 요소: 전기자·계자·정류자**
- 철심: 규소강판(1~1.4%) 성층 → 철손 감소

| 권선법 | 중권 | 파권 |
|---|---|---|
| 병렬회로수 a | 극수 p | 2 |
| 용도 | 저전압 대전류 | 고전압 소전류 |
| 균압환 | 필요 | 불필요 |

## 1.2 유도 기전력 ★
**E = pZφN/(60a) = kφN [V]**

## 1.3 전기자 반작용 ★★★
- 감자작용(주자속 감소), 편자작용(중성축 이동: 발전기→회전방향, 전동기→반대)
- **대책: 보상권선(최유효, 전기자 전류와 반대방향), 보극, 브러시 이동**

## 1.4 정류 개선
양호한 정류: ① 리액턴스 전압 작게 ② 보극(전압정류) ③ 탄소 브러시(저항정류) ④ 정류주기 길게

## 1.5 발전기 종류
- 분권: **잔류자기 필요**, 역회전 시 발전 불가
- 직권: 무부하 시 발전 불가
- 차동복권: 수하특성 → 용접기
- 자여자 전압확립: 잔류자기 + 임계저항>계자저항 + 회전방향 일치

## 1.6 직류전동기 ★★★
- 역기전력 E = V - IaRa, **회전수 N = (V-IaRa)/kφ**
- 토크 **T = kφIa**, 직권은 T ∝ Ia²
- **분권: 계자 단선 시 위험속도 / 직권: 무부하(벨트) 운전 금지** ← 초빈출

## 1.7 속도제어 ★★★
| 방법 | 특징 |
|---|---|
| **전압제어**(워드레오나드·일그너) | 광범위·고효율·정토크, 일그너=플라이휠 |
| 계자제어 | 정출력 |
| 저항제어 | 효율 나쁨 |

## 1.8 제동·효율
- 회생제동: 전원 반환(전기철도)
- **최대효율 조건: 철손 = 동손**
- 규약효율: 발전기 η=출력/(출력+손실), 전동기 η=(입력-손실)/입력

# 제2장 동기기 ★★★★★ (회당 3.7문항)

## 2.1 기본
- **동기속도 Ns = 120f/p [rpm]**
- **회전계자형 채용**: 전기자 고전압 절연 유리, 계자는 저전압, 기계적 견고
- 터빈발전기: 2~4극 고속 원통형, **수소냉각**(풍손 1/10, 폭발 우려로 순도 85%↑)

## 2.2 권선법 ★★★
- **단절권**: 고조파 제거, 동량 절약, kp = sin(βπ/2)
- **분포권**: 고조파 감소·파형 개선, 누설 리액턴스 감소
- **E = 4.44 f N φ kw [V]**

## 2.3 전기자 반작용 (발전기 기준) ★★★
| 부하 | 작용 |
|---|---|
| R(동상) | 교차자화 |
| **L(지상)** | **감자** |
| **C(진상)** | **증자** |
(전동기는 반대)

## 2.4 단락비·단락전류 ★★★
- **단락비 Ks = 100/%Z**
- **단락비 큰 기계(철기계)**: 전압변동률 작음, 안정도 좋음, **철손 커 효율 나쁨**, 대형 고가
- **돌발 단락전류 제한: 누설 리액턴스** / 지속 단락전류: 동기 리액턴스
- 출력 P = EVsinδ/Xs (원통형 δ=90° 최대, 돌극형 60°)

## 2.5 병렬운전 조건 ★★★ (매년 수준)
| 불일치 | 현상 |
|---|---|
| **크기** | **무효순환전류(무효횡류)** |
| **위상** | **유효순환전류(동기화전류)** |
| 주파수 | 난조 |
| 파형 | 고조파 순환전류 |

## 2.6 난조·안정도
- **난조 방지: 제동권선** (기동토크 발생 겸용)
- 안정도↑: 단락비 크게, 플라이휠(관성), 속응여자

## 2.7 동기전동기 ★★★
- 장점: **역률 조정 가능(1.0)**, 정속도 / 단점: 기동토크 0, 난조
- 기동법: 자기동법(제동권선, **계자 단락** 후 기동), 유도전동기법
- **V곡선: 부족여자→지상(리액터), 과여자→진상(콘덴서)**, 최저점=역률1

# 제3장 변압기 ★★★★★ (합산 회당 5.1문항)

## 3.1 원리
- **E = 4.44 f N φm [V]**
- 권수비 a = N₁/N₂ = E₁/E₂ = I₂/I₁ = √(Z₁/Z₂)
- 여자전류: **제3고조파 포함**(자기포화·히스테리시스)

## 3.2 절연유·구조 ★★
- 구비조건: 절연내력 클 것, **점도 낮을 것**, 인화점 높을 것, 응고점 낮을 것
- **콘서베이터: 절연유 열화 방지** / 열화방지: 질소봉입·브리더

## 3.3 시험 ★★★
| 시험 | 구하는 것 |
|---|---|
| **무부하시험** | **철손, 여자전류** |
| **단락시험** | **동손, 임피던스전압, 전압변동률** |

## 3.4 전압변동률 ★★
**ε = p cosθ + q sinθ** (지상 +, 진상 -)
- 최대 전압변동률 = √(p²+q²), 역률 1일 때 ε = p

## 3.5 손실·효율 ★★★★
- 히스테리시스손 ∝ V²/f (**주파수 반비례**), 와류손 ∝ V² (**주파수 무관**)
- **최대효율: Pi = (1/m)²Pc**, 1/m = √(Pi/Pc)
- 전일효율 최대: 24Pi = ΣhPc

## 3.6 3상 결선 ★★★
- **Δ-Y: 승압용 / Y-Δ: 강압용** (30° 위상차)
- Y-Y: 제3고조파 → 통신장해 (Y-Y-Δ 3권선으로 사용, Δ=안정권선)
- **V결선: 출력 √3P₁, 이용률 86.6%, 출력비 57.7%** ← 초빈출
- 3상→2상: **스코트(T) 결선** / 3상→6상: 포크 결선

## 3.7 병렬운전 ★★★
- 조건: 극성·권수비·%Z 같을 것, 저항/리액턴스비 같을 것
- 부하분담: %Z에 반비례, 용량에 비례
- **Δ-Δ와 Δ-Y 조합 불가(위상차 30°)**

## 3.8 특수 변압기 ★★
- **단권 변압기: 자기용량/부하용량 = (Vh-Vl)/Vh**
- **PT: 2차 110V, 단락 금지 / CT: 2차 5A, 개방 금지(고전압 유도)** ← 초빈출
- CT 점검 시 2차측 단락 후 작업

# 제4장 유도전동기 ★★★★★

## 4.1 슬립
**s = (Ns-N)/Ns** — 정지 s=1, 동기속도 s=0, 전부하 0.03~0.05

## 4.2 회전 시 2차 (초빈출)
- 2차 기전력 **sE₂**, 2차 주파수 **sf₂**

## 4.3 전력 변환 ★★★
**P₂ : Pc2 : P₀ = 1 : s : (1-s)**
- 2차 동손 = sP₂, 출력 = (1-s)P₂, 2차 효율 = 1-s = N/Ns

## 4.4 토크
- **T ∝ V²** (전압 80% → 토크 64%)
- 최대토크 슬립 sm = r₂/x₂, **최대토크 크기는 2차 저항 무관**

## 4.5 비례추이 ★★★ (권선형 핵심)
- r₂/s = (r₂+R)/s′ — 기동토크↑ + 기동전류↓
- **가능: 토크·1차전류·역률 / 불가능: 출력·효율·2차동손** ← 초빈출

## 4.6 기동법 ★★★
- 농형: 직입(5kW↓), **Y-Δ(5~15kW, 전류·토크 1/3)**, 기동보상기(15kW↑), 리액터
- 권선형: 2차 저항(비례추이), 게르게스법
- **크로우링 방지: 사구(skewed slot)** / 게르게스 현상: s=0.5 부근 정체

## 4.7 속도제어 ★★
- **VVVF(주파수)**: 선박·방직 / 극수변환 / 전압제어
- 권선형: 2차저항, **2차여자(크레머=정출력, 세르비우스=전원반환)**
- 종속법: 직렬 N=120f/(p₁+p₂)

## 4.8 시험·단상유도기
- **원선도 작성: 저항측정 + 무부하시험 + 구속시험** ← 초빈출
- 단상 기동토크 순위: **반발기동 > 반발유도 > 콘덴서기동 > 분상 > 셰이딩코일** ← 초빈출

# 제5장 정류기·전력변환 ★★★★

## 5.1 정류회로 수치 (초빈출 암기)
| 방식 | 직류전압 | 맥동률 | 맥동주파수 |
|---|---|---|---|
| 단상 반파 | 0.45E | 121% | f |
| **단상 전파** | **0.9E** | **48%** | 2f |
| 3상 반파 | 1.17E | 17% | 3f |
| **3상 전파** | **1.35E** | **4%** | 6f |

- PIV: 단상 반파 √2E(=πEd)
- 다이오드 **직렬=과전압 방지, 병렬=과전류 방지** ← 초빈출

## 5.2 SCR ★★★
- PNPN 4층, **턴온 후 게이트 제어력 상실**, 소호는 유지전류 이하로
- 래칭전류 > 유지전류

| 소자 | 특징 |
|---|---|
| **GTO** | 게이트로 턴오프 가능 |
| **TRIAC** | 양방향(교류 제어) |
| IGBT | MOSFET+BJT, 고속 대전력 |

## 5.3 전력변환 분류 (초빈출)
- 컨버터: AC→DC / **인버터: DC→AC** / **초퍼: DC→DC** / **사이클로컨버터: AC→AC(주파수)**
- 강압 초퍼 Vo = D·Vs
