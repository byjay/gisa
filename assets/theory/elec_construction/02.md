# 제1장 선로정수와 코로나 ★★

## 1.1 선로정수 (R, L, C, G)
- 선로정수는 전선 종류·굵기·배치에 의해 결정 (전압·전류·역률과 무관) ← 빈출 지문

**작용 인덕턴스**: L = 0.05 + 0.4605 log₁₀(D/r) [mH/km]
**작용 정전용량**: C = 0.02413/log₁₀(D/r) [μF/km]
- D: 등가 선간거리(기하평균) D = ³√(D₁D₂D₃)
- r: 전선 반지름

**복도체(다도체)의 효과(빈출)**:
- 인덕턴스 감소, 정전용량 증가 → 송전용량 증가
- 코로나 임계전압 상승 → 코로나 방지 ← 주목적
- 안정도 증가
- 단점: 페란티 효과 증대, 소도체 충돌(스페이서 설치)

## 1.2 연가 (Transposition)
- 목적: 선로정수 평형 → 통신선 유도장해 경감, 직렬공진 방지 ← 빈출
- 방법: 전 구간을 3의 배수로 등분하여 각 상 위치 교환

## 1.3 코로나 ★
- **파열극한 전위경도**: DC 30kV/cm, **AC 21.1kV/cm** (실효값) ← 빈출
- 코로나 임계전압: E₀ = 24.3 m₀m₁δ d log₁₀(D/r) [kV]
  - 날씨 나쁘면(비·눈) m₁ 작아져 임계전압 낮아짐 → 코로나 발생 쉬움
- **코로나 영향**: 코로나 손실(Peek식: 손실 ∝ (E-E₀)², f+25에 비례), 오존(O₃) 발생 → 전선 부식(초산 생성), 통신선 유도장해, 소호리액터 소호능력 저하
- **방지책**: 굵은 전선(ACSR), 복도체, 가선금구 개량

# 제2장 송전선로 특성 ★★★★★ (회당 4.1문항 — 전 과목 최다)

## 2.1 단거리 송전선로 (50km 이하, R·L만 고려)
**전압강하**: e = Vs - Vr = √3 I(Rcosθ + Xsinθ) = P/Vr·(R + Xtanθ)

**빈출 비례 관계 (완벽 암기)**:
| 항목 | 관계식 | 전압 n배 시 |
|---|---|---|
| 송전전력 | P ∝ V² | n²배 |
| 전압강하 e | e ∝ 1/V | 1/n |
| **전압강하율 ε** | ε ∝ 1/V² | 1/n² |
| 전력손실 Pl | Pl ∝ 1/V² | 1/n² |
| 전선단면적 A | A ∝ 1/V² | 1/n² |

- 전압강하율 ε = (Vs-Vr)/Vr ×100%
- 전압변동률 δ = (Vr0 - Vr)/Vr ×100% (무부하-전부하 수전단)
- **전력손실률 일정 시 P ∝ V²** ← 초빈출

## 2.2 중거리 송전선로 (50~100km, 4단자정수)
- T형 회로, π형 회로 해석
- **4단자 정수**: Vs = AVr + BIr, Is = CVr + DIr
  - **AD - BC = 1** ← 빈출
  - A: 전압비(무부하), B: 임피던스 차원, C: 어드미턴스 차원, D: 전류비
- 대칭 회로: A = D
- π형: A = D = 1 + ZY/2, B = Z, C = Y(1 + ZY/4)

## 2.3 장거리 송전선로 (100km 초과, 분포정수)
- **특성(파동) 임피던스**: Z₀ = √(Z/Y) = √(L/C) ≒ 300~500Ω (가공선 약 400Ω)
  - **거리와 무관** ← 초빈출 지문
- **전파정수**: γ = √(ZY) = α + jβ
- 무손실 선로: 전파속도 v = 1/√(LC) ≒ 3×10⁵ km/s

## 2.4 송전용량
- **송전용량 일반식**: P = (Vs·Vr/X)·sinδ [MW] ← 초빈출
  - δ: 상차각(보통 30~40°), X: 리액턴스
- 송전용량 계수법: P = k·Vr²/l
- **경제적 송전전압(Still의 식)**: V = 5.5√(0.6l + P/100) [kV]

## 2.5 페란티 효과 ★
- **무부하·경부하 시 수전단 전압 > 송전단 전압** 현상
- 원인: 선로의 **정전용량**(진상 충전전류)
- 대책: **분로(병렬) 리액터** 설치 ← 초빈출

## 2.6 조상설비 ★★ (빈출 비교표)
| 항목 | 동기조상기 | 전력용 콘덴서 | 분로 리액터 |
|---|---|---|---|
| 조정 | 진상·지상 양용 | 진상만 | 지상만 |
| 조정 방식 | 연속적 | 계단적(불연속) | 계단적 |
| 시충전(시송전) | 가능 | 불가 | 불가 |
| 전력손실 | 큼 | 작음 | 작음 |
| 가격 | 고가 | 저렴 | 저렴 |

**전력용 콘덴서 부속설비(빈출)**:
- **직렬 리액터**: 제5고조파 제거 — 이론상 4%, 실제 5~6%
- **방전 코일**: 잔류전하 방전 (감전 방지)

**역률 개선 콘덴서 용량**: Qc = P(tanθ₁ - tanθ₂) [kVA]

## 2.7 전력원선도 ★
- 가로축: 유효전력, 세로축: 무효전력
- **반지름: ρ = Vs·Vr/B**
- 원선도에서 알 수 있는 것: 송수전 전력, 조상용량, 수전단 역률, 전력손실
- **알 수 없는 것: 과도 안정 극한전력, 코로나 손실** ← 초빈출

# 제3장 고장계산과 대칭좌표법 ★★★★★ (회당 2.5문항)

## 3.1 %임피던스법
**%Z = (Z·P)/(10V²)** (P[kVA], V[kV])
- **단락전류**: Is = (100/%Z)·In
- **단락용량**: Ps = (100/%Z)·Pn [MVA]
- 기준용량 환산: %Z' = %Z × (기준용량/자기용량)

## 3.2 대칭좌표법 ★★★
불평형 3상을 3개 대칭분으로 분해:
- **영상분** V₀ = ⅓(Va + Vb + Vc)
- **정상분** V₁ = ⅓(Va + aVb + a²Vc)
- **역상분** V₂ = ⅓(Va + a²Vb + aVc)
- a = 1∠120°, 1 + a + a² = 0

**고장별 대칭분 (초빈출 암기)**:
| 고장 종류 | 필요한 대칭분 |
|---|---|
| 3상 단락 | 정상분만 |
| 선간 단락 | 정상분 + 역상분 |
| **1선 지락** | **정상분 + 역상분 + 영상분 (모두)** |

- **1선 지락전류**: Ig = 3E/(Z₀+Z₁+Z₂) — 영상전류 I₀ = I₁ = I₂ ← 초빈출
- 영상 임피던스: 변압기 Z₀=Z₁=Z₂, 송전선 Z₀ > Z₁ = Z₂ (약 4배)
- **영상전류는 통신선 유도장해의 원인** ← 빈출

## 3.3 발전기 기본식
- V₀ = -Z₀I₀, V₁ = Ea - Z₁I₁, V₂ = -Z₂I₂

# 제5장 이상전압과 방호 ★★★

## 5.1 이상전압 종류
- 내부: 개폐 서지(무부하 충전전류 개방 시 최대 — 재점호), 페란티
- 외부: 뇌(직격뢰·유도뢰)
- **개폐 이상전압은 개폐 저항기로 억제**

## 5.2 진행파의 반사와 투과
- 반사계수: β = (Z₂-Z₁)/(Z₂+Z₁)
- 투과계수: γ = 2Z₂/(Z₂+Z₁)
- 무반사 조건: Z₁ = Z₂

## 5.3 방호 설비 ★★
**가공지선**: 직격뢰 차폐(차폐각 작을수록 보호율↑, 30~45°), 유도뢰 차폐, 통신선 유도장해 경감
**매설지선**: **탑각 접지저항 감소 → 역섬락 방지** ← 초빈출
**아킹혼(초호각)**: 애자련 보호(섬락 시 애자 파손 방지)

## 5.4 피뢰기 (LA) ★★★
- 구성: **직렬 갭 + 특성요소**
- **역할: 이상전압 내습 시 대지로 방전, 속류 차단**
- **정격전압: 속류를 차단할 수 있는 최고 상용주파 교류전압** ← 초빈출
- **제한전압: 방전 중 피뢰기 단자에 남는 전압** ← 초빈출
- 구비조건: 제한전압 낮을 것, 속류차단 능력 클 것, 상용주파 방전개시전압 높을 것, 충격방전 개시전압 낮을 것 ← 초빈출
- **절연협조**: 피뢰기의 제한전압을 기준(최저)으로 계통 절연 설계
  - 절연 강도 순서: **선로애자 > 결합콘덴서 > 기기 부싱 > 변압기 > 피뢰기(최저)**

## 5.5 절연협조·BIL
- BIL(기준충격절연강도): 뇌 임펄스 내전압 시험값

- **정격차단시간**: 트립코일 여자~아크 소호까지 (3, 5, 8Hz 표준) ← 빈출
- 표준 동작책무: O - 0.3초 - CO - 3분 - CO (일반형)

## 7.3 개폐기 구분 ★★
| 기기 | 차단 능력 |
|---|---|
| 차단기(CB) | 부하전류 + **고장(단락)전류** |

| 부하개폐기(LBS) | 부하전류만 |
| 전력퓨즈(PF) | **단락전류** 차단 (과부하 부적합) |

**인터록**: 차단기가 열려 있어야만 단로기 조작 가능 ← 초빈출
**조작 순서**: 급전 시 DS 닫고→CB / 정전 시 CB 열고→DS

**전력퓨즈 장단점**: 소형 경량·저렴·고속차단·보수 간단 / 재투입 불가·과도전류에 용단 가능

# 제8장 배전 ★★★★ (회당 1.7문항)

## 8.1 배전방식 비교
- **수지식(가지식)**: 시설비 저렴, 정전 범위 큼, 전압변동 큼 — 농어촌
- **루프식(환상식)**: 공급 신뢰도↑, 전압강하·전력손실 감소
- **저압 뱅킹**: 변압기 2차측 병렬 — **캐스케이딩** 현상 주의(구분 퓨즈로 대비) ← 빈출
- **네트워크(망상식)**: 무정전 공급, 신뢰도 최고, 건설비 최고, 역류 방지에 **네트워크 프로텍터** ← 빈출

## 8.2 수요와 부하 (초빈출 공식)
- **수용률 = 최대수용전력 / 설비용량** (≤1)
- **부등률 = 개별 최대수용전력의 합 / 합성 최대수용전력** (≥1) ← 클수록 설비 이용률↑
- **부하율 = 평균전력 / 최대전력**
- 합성 최대전력 = (설비용량×수용률)/부등률
- **손실계수 H와 부하율 F**: F² ≤ H ≤ F, H = αF + (1-α)F²

## 8.3 배전선 전기 공급 방식 비교 ★
1선당 공급전력 비 (단상2선식 = 100% 기준):
| 방식 | 1선당 전력비 | 전선 소요량 |
|---|---|---|
| 단상 2선식 | 100% | 100% |
| 단상 3선식 | 133% | 37.5% |
| 3상 3선식 | 115% | 75% |
| **3상 4선식** | **150%** | **33.3%** ← 최유리 |

**단상 3선식 주의(빈출)**: 중성선 단선 시 전압 불평형 → **밸런서** 설치(여자 임피던스 큼, 누설 임피던스 작음), 중성선에 퓨즈 설치 금지

## 8.4 전압 조정·플리커
- 배전 전압 조정: 주상변압기 탭, 유도전압조정기(IR), 승압기
- 플리커 대책(전력 공급측): 단락용량 큰 계통에서 공급, 전용 변압기·전용선

## 8.5 부하 형태별 계산
- 말단 집중부하 vs 균등 분산부하: 전압강하 1/2배, 전력손실 **1/3배** ← 초빈출

# 제9장 수력발전 ★★★

## 9.1 수력 기본
- **이론 출력**: P = 9.8QH [kW] (Q: 유량 m³/s, H: 유효낙차 m)
- 실제 출력: P = 9.8QHη [kW]
- **연속의 정리**: Q = Av = 일정
- **베르누이 정리**: 위치수두 + 압력수두(P/w) + 속도수두(v²/2g) = 일정
- 물의 분출속도: v = √(2gH)

## 9.2 유량 도표
- 유황곡선: 갈수량(355일), 저수량(275일), 평수량(185일), 풍수량(95일) ← 빈출
- 적산유량곡선: 저수지 용량 결정 ← 빈출

## 9.3 수차 종류 ★★
| 낙차 | 수차 |
|---|---|
| 고낙차(300m~) | **펠턴**(충동수차 — 니들밸브, 디플렉터) |
| 중낙차(50~500m) | **프란시스**(반동) |
| 저낙차(~90m) | 프로펠러, **카플란**(가동익) |
| 조력·초저낙차 | 튜블러(원통형) |

- **특유속도(비속도)**: Ns = N·P^½/H^(5/4) ← 빈출
  - 순서: 펠턴(최소) < 프란시스 < 카플란·프로펠러(최대)
  - 낙차 클수록 특유속도 작음
- **캐비테이션(공동현상)**: 방지 — 흡출관 높이 낮춤, 특유속도 작게, 침식 강한 재료 ← 빈출
- **흡출관**: 반동수차의 낙차 회수(러너 출구~방수면) — 펠턴에는 없음 ← 빈출
- **조속기 동작 순서: 평속기→배압밸브→서보모터→복원기구** ← 빈출
- **수격작용 방지: 조압수조(서지탱크)**, 수차 입구 밸브 완폐

## 9.4 양수발전
- 첨두부하용, 심야 잉여전력으로 양수
- 양수 소요전력: P = 9.8QH/η [kW] (효율로 나눔)

# 제10장 화력발전 ★★★

## 10.1 열역학 기초
- 1 kWh = 860 kcal ← 초빈출
- 엔탈피: 물·증기의 보유 열량 [kcal/kg]
- **랭킨 사이클**: 급수펌프(단열압축)→보일러(등압가열)→터빈(단열팽창)→복수기(등압냉각) ← 초빈출
- **재생 사이클**: 터빈 중간 증기 추출(추기) → **급수 가열**
- **재열 사이클**: 고압터빈 배기를 재열기로 재가열 → 저압터빈
- 재생·재열 병용 = 재생재열 사이클(효율 최고)

## 10.2 발전소 효율
**η = 860W / (mH) × 100%** (m: 연료량 kg, H: 발열량 kcal/kg, W: 발전량 kWh) ← 초빈출 계산

## 10.3 보일러 부속설비 (초빈출 매칭)
| 설비 | 역할 |
|---|---|
| **과열기** | 포화증기 → 과열증기 |
| **재열기** | 고압터빈 배기 재가열 |
| **절탄기** | 배기가스 여열로 **급수 예열** ← 초빈출 |
| **공기예열기** | 배기가스 여열로 연소용 공기 예열 |
| **복수기** | 터빈 배기 응축(진공, 열손실 최대 약 50%) ← 초빈출 |
| 급수가열기 | 추기로 급수 가열(재생) |
| 탈기기 | 급수 중 산소(O₂) 제거 — 부식 방지 ← 빈출 |

- 수냉벽: 노벽 보호+증발량 증가, 복사열 흡수 최대
- 터빈 조속 방식, 캐리오버 현상 등

# 제11장 원자력발전 ★★

## 11.1 원자로 구성 (초빈출 매칭표)
| 구성 | 역할 | 재료 |
|---|---|---|
| 핵연료 | 핵분열 | 농축우라늄(U-235 2~4%) |
| **감속재** | 고속 중성자 → 열중성자로 감속 | 경수, 중수, 흑연, 베릴륨 ← 빈출 |
| **제어봉** | 중성자 흡수 → 출력 조절 | **카드뮴(Cd), 붕소(B), 하프늄(Hf)** ← 초빈출 |
| 냉각재 | 열 반출 | 경수, 중수, 탄산가스, 헬륨, 나트륨 |
| 반사체 | 중성자 누설 방지 | 경수, 흑연, 베릴륨 |
| 차폐재 | 방사선 차단 | 콘크리트, 납, 물 |

- 감속재 구비조건: 중성자 흡수 단면적 **작을 것**, 감속능 클 것, 원자량 작을 것

## 11.2 원자로 종류
- **PWR(가압수형)**: 국내 대부분, 경수 감속·냉각, **증기발생기**로 1·2차 분리, 농축우라늄
- **BWR(비등수형)**: 원자로 내 직접 비등, 증기발생기·열교환기 없음, 일본 후쿠시마형
- CANDU(가압중수형): 중수 감속, **천연우라늄** 사용(월성)
- 핵분열 1g당 에너지: 약 1g U-235 = 석탄 3톤

# 제12장 안정도 ★★

## 12.1 안정도 종류
- **정태 안정도**: 완만한 부하 변화에 대한 안정
- **과도 안정도**: 급격한 외란(고장·개폐)에 대한 안정
- 동태 안정도: AVR 등 제어 포함

## 12.2 안정도 향상 대책 (초빈출 리스트)
1. **직렬 리액턴스 감소**: 복도체, 병행 2회선, **직렬 콘덴서** 삽입
2. **전압변동 억제**: 속응 여자방식, 계통 연계, 중간 조상방식
3. **고장 충격 경감**: 고속 차단, **고속도 재폐로**, 소호리액터 접지
4. 발전기 입출력 불평형 억제: 조속기 신속 동작, 제동저항

- 송전전력 P = (VsVr/X)sinδ → X 작을수록, V 클수록 안정도↑
