# 제1장 유체 기초성질

- **압축률**
- **표면장력**
- **모세관**

## 기출 반복 포인트

**Q. 유체에 관한 설명 중 옳은 것은?**

→ 정답: **유체에 압력을 가하면 체적이 줄어드는 유체는 압축성 유체이다.** (2회 출제)

**Q. 베르누이 방정식을 적용할 수 있는 기본 전제조건으로 옳은 것은?**

→ 정답: **비압축성 흐름, 비점성 흐름, 정상 유동** (2회 출제)

## 필수 공식

- **연속방정식**: `Q = A·V` — 유량 = 단면적 × 유속. 배관 축소 시 유속 증가.
- **베르누이 방정식**: `P/γ + V²/2g + Z = 일정` — 압력수두+속도수두+위치수두 보존. 펌프 양정 계산의 뿌리.
- **펌프 동력**: `P = γQH/η` — 축동력 = 비중량×유량×전양정/효율. kW 환산 주의.
- **레이놀즈수**: `Re = ρVD/μ` — 층류 Re<2100, 난류 Re>4000. 유동 판별 기준.
